# Kokoshka · «Анамнез»

Текстовая RPG-симулятор ординатора-психиатра. Последний семестр ординатуры — лекции, семинары-разборы пациентов, сессия и аккредитация, — а потом самостоятельная работа: приём, ночные дежурства, подработки, аренда, стресс и рыжая кошка Кокошка.

## Где играть

- **Android.** Скачай [anamnez.apk](https://github.com/Pozornyk3000/Kokoshka/releases/latest/download/anamnez.apk) на телефон, открой и разреши установку из этого источника. Работает без интернета и без разрешений; новая версия ставится поверх старой, сохранения остаются. Все версии — в [релизах](https://github.com/Pozornyk3000/Kokoshka/releases).
- **В браузере (телефон или компьютер).** Включи GitHub Pages: *Settings → Pages → Build and deployment → Deploy from a branch*, ветка с игрой, папка `/docs`. Игра откроется по адресу `https://pozornyk3000.github.io/Kokoshka/`, её можно «Добавить на главный экран» — дальше она работает и без интернета.
- **Одним файлом.** В релизе лежит `anamnez.html` — вся игра в одном файле (шрифты внутри), открывается в любом браузере.
- **Из исходников.** Открой `index.html` — сборка не нужна.

Игра сохраняется автоматически. Чтобы перенести прогресс между устройствами, в меню есть «Скопировать код сохранения» и «Загрузить из кода».

## Как играть

- **День** делится на утро, день, вечер и ночь. Действия тратят время, энергию и деньги, снимают или добавляют стресс.
- **Учёба (недели 1–3).** Утром — лекция профессора Корсаковой с блиц-опросом, днём — семинар у доцента Кандинского: живой пациент. Пропуски отрабатываются вечером, без отработок к сессии не допустят.
- **Клинический случай:** беседа (ограниченное число вопросов, контакт с пациентом можно потерять) → психический статус (отметить симптомы) → синдром и диагноз по МКБ-10 → тактика → разбор с объяснением ошибок и «клинической жемчужиной».
- **Сессия (неделя 4):** экзамен по клинической психиатрии, экзамен по терапии и неотложке (ситуационные задачи) и аккредитация (тест + задача). Хороший рейтинг даёт «автомат».
- **Работа:** ПНД, психиатрическая больница, частная клиника или кафедра. Подработки — медкомиссии, онлайн-консультации, дежурства, занятия со студентами. Есть «неделя на автопилоте» для перемотки.
- **Жизнь:** аренда и еда списываются раз в неделю (расчётный листок), высокий стресс ведёт к выгоранию, низкое здоровье — к больничному. Знания по темам дают подсказки «клинического чутья».
- **Мечта** — цель игры: своя квартира, свой кабинет, наука или жизнь без выгорания.

Клинические случаи вымышлены и упрощены для обучения; игра не заменяет учебник, супервизию и консультацию врача.

## Устройство

Чистый JavaScript без зависимостей, классические скрипты в общем пространстве `window.A`.

| Папка | Что внутри |
| --- | --- |
| `js/core` | утилиты, календарь, сохранения (localStorage + облако Claude, если доступно) |
| `js/game` | движок времени и показателей, действия, оценка клинических случаев и экзаменов |
| `js/data` | контент: лекции, клинические случаи, мини-задачи, события, глоссарий, финалы |
| `js/art` | процедурная SVG-графика: сцены со сменой времени суток и сезона, портреты с эмоциями, иконки |
| `js/ui` | экраны и интерфейс |
| `tools` | сборка, проверка данных, автоигрок и симуляция экономики |
| `assets` | шрифты (SIL OFL 1.1) и иконки приложения |
| `docs` | собранная версия для GitHub Pages (PWA, работает офлайн) — генерируется, руками не править |
| `android` | приложение для Android: окно WebView, в которое встроена игра |

Инструменты:

```sh
node tools/validate.mjs                 # проверить формат и согласованность контента
node tools/sim.mjs 180                  # прогнать 180 игровых дней без интерфейса (баланс)
node tools/build.mjs                    # собрать dist/anamnez.html — игра одним файлом
node tools/build.mjs --site docs        # обновить версию для GitHub Pages (после любых правок игры)
NODE_PATH=$(npm root -g) node tools/autoplay.cjs index.html 600   # автоигрок в headless Chromium (нужен playwright)
NODE_PATH=$(npm root -g) node tools/bridge-test.cjs docs/index.html  # связка игры с Android-приложением
```

### Android

APK собирает GitHub Actions (`.github/workflows/android.yml`): проверяет данные, гоняет автоигрока, собирает APK, проходит игру на эмуляторах Android 11 и 15 и выкладывает файлы в релиз `android-latest`. Локально (нужны JDK 17 и Android SDK):

```sh
node tools/build.mjs --site android/app/src/main/assets/www
cd android && ./gradlew assembleRelease     # → app/build/outputs/apk/release/app-release.apk
```

Приложение — одна активность с WebView (`MainActivity.java`). Игра открывается с зарезервированного адреса `https://appassets.androidplatform.net/` прямо из APK, в сеть ничего не уходит. Сохранения дублируются в файлы приложения, системная кнопка «назад» закрывает окна и вкладки игры. Ключ подписи `android/keystore/anamnez.jks` лежит в репозитории намеренно, чтобы обновления ставились поверх; для магазина приложений замени его своим. Иконки рисует `tools/icons.cjs`, шрифты скачивает `tools/fonts.mjs`.
