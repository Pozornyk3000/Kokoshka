# Kokoshka · «Анамнез»

Текстовая RPG-симулятор ординатора-психиатра. Последний семестр ординатуры — лекции, семинары-разборы, собственные пациенты на практике, ГИА, диплом и аккредитация, — а потом самостоятельная работа: палаты в стационаре или приём, ночные дежурства, подработки, аренда, стресс и рыжая кошка Кокошка.

## Где играть

- **Android.** Скачай [anamnez.apk](https://github.com/Pozornyk3000/Kokoshka/releases/latest/download/anamnez.apk) на телефон, открой и разреши установку из этого источника. Работает без интернета и без разрешений; новая версия ставится поверх старой, сохранения остаются. Все версии — в [релизах](https://github.com/Pozornyk3000/Kokoshka/releases).
- **В браузере (телефон или компьютер).** Включи GitHub Pages: *Settings → Pages → Build and deployment → Deploy from a branch*, ветка с игрой, папка `/docs`. Игра откроется по адресу `https://pozornyk3000.github.io/Kokoshka/`, её можно «Добавить на главный экран» — дальше она работает и без интернета.
- **Одним файлом.** В релизе лежит `anamnez.html` — вся игра в одном файле (шрифты внутри), открывается в любом браузере.
- **Из исходников.** Открой `index.html` — сборка не нужна.

Игра сохраняется автоматически. Чтобы перенести прогресс между устройствами, в меню есть «Скопировать код сохранения» и «Загрузить из кода».

## Как играть

- **Режимы.** «Полный путь» — с последнего семестра ординатуры: учёба, практика, ГИА, диплом, аккредитация и потом работа. «Старт с врача» — диплом и аккредитация уже есть (оценки в дипломе зависят от предыстории), игра начинается с выбора работы.
- **Справочники** — препараты, клинические рекомендации, симптомы и конспекты лекций — открываются с титульного экрана без начала игры и из меню.
- **Сложность** выбирается при создании персонажа и меняется в меню. «Лёгкая» — больше подсказок клинического чутья, в листе назначений отмечены первая и вторая линия по КР. «Обычная» — диагноз выбирают из нескольких вариантов. «Сложная» — диагноз ставят сами из **полного списка МКБ-10** (весь класс F и коды других классов для дифференциальной диагностики, поиск по коду и словам; верная рубрика с другим уточнением — полбалла), без подсказок, а дозы и время приёма — по справочнику.
- **Тренажёр** — с титула и из меню, на игру не влияет: тест в формате аккредитации на 20 или 80 вопросов (порог 70%, разбор в конце), тесты по темам с объяснением после каждого ответа, работа над ошибками и ситуационные задачи «поставьте диагноз по МКБ-10» по виньеткам клинических случаев. 281 вопрос по десяти темам и трём уровням: базовый (определения, критерии, сроки), средний (клинические ситуации, тактика, право) и сложный — 100 развёрнутых случаев в стиле зарубежных экзаменов для ординаторов (британский MRCPsych, американские PRITE и USMLE), с пометками, где российская практика отличается. Тест в формате аккредитации можно проходить на время — 45 секунд на вопрос, как на настоящем тестировании (80 вопросов за 60 минут). **Конструктор психического статуса** — 17 пациентов на трёх уровнях: по наблюдению, словам пациента и родственников статус собирают по разделам (внешний вид, сознание, контакт, восприятие, мышление, эмоции, воля, когнитивные функции, суицидальный риск, критика), выбирая точные формулировки; среди вариантов — ошибки по содержанию и ярлыки вроде «неадекватен» и «бредит». В конце — разбор по разделам, образец статуса и памятка. У тренажёра свои 22 достижения — от первого теста до «всего банка» и «статуса без ярлыков»; результаты, ошибки и достижения хранятся на устройстве. Вопросы написаны для игры и **не являются официальными заданиями аккредитации** — для настоящих в тренажёре есть ссылка на репетиционный экзамен Методического центра аккредитации специалистов (selftest.mededtech.ru, открывается в браузере).
- **Звук.** Тихий генеративный эмбиент без аудиофайлов (Web Audio): настроение меняется по месту и времени суток, дома иногда мурлычет Кокошка, в дождливые дни слышен дождь, на экзаменах тикают часы. Включается после первого касания, в фоне молчит; выключатель и громкость — в меню.
- **День** делится на утро, день, вечер и ночь. Действия тратят время, энергию и деньги, снимают или добавляют стресс.
- **Учёба (недели 1–3).** Утром — лекция профессора Корсаковой с блиц-опросом, днём — семинар у доцента Кандинского: живой пациент. Пропуски отрабатываются вечером, без отработок к сессии не допустят. Днём или вечером в будни — **практикум «психический статус»** в том же конструкторе, что и в тренажёре: первые пациенты — базового уровня, дальше сложнее; Кандинский проверяет запись (знания по психопатологии и опыт).
- **Клинический случай:** беседа (ограниченное число вопросов, контакт с пациентом можно потерять) → психический статус (отметить симптомы) → синдром и диагноз по МКБ-10 → тактика → разбор с объяснением ошибок и «клинической жемчужиной».
- **Практика (дни 8–19).** Каждый учебный день — обход своих пациентов в отделении кафедры (см. «Курация» ниже). Зачёт по практике — допуск к ГИА; без него — отработка в сессию.
- **Сессия (неделя 4):** экзамен по психиатрии (хороший рейтинг даёт «автомат»), затем **государственная итоговая аттестация** — решением ГЭК выдаётся диплом об окончании ординатуры с приложением (квалификация «врач-психиатр»; «с отличием» в ординатуре не бывает), и **первичная специализированная аккредитация**: тестирование (порог 70%) и ситуационные задачи, результат вносится в ФРМР.
- **Работа:** ПНД, психиатрическая больница, частная клиника или кафедра. В больнице каждый рабочий день начинается с обхода своих палат (3–4 пациента), в ПНД, клинике и на кафедре — с амбулаторного приёма (см. ниже). Подработки — медкомиссии, онлайн-консультации, дежурства, занятия со студентами. Есть «неделя на автопилоте» для перемотки — пациентов тогда ведёт коллега.
- **Жизнь:** аренда и еда списываются раз в неделю (расчётный листок), высокий стресс ведёт к выгоранию, низкое здоровье — к больничному. Знания по темам дают подсказки «клинического чутья».
- **Мечта** — цель игры: своя квартира, свой кабинет, наука или жизнь без выгорания.

### Курация

Пациенты отделения живут по дням: болезнь течёт сама, лекарства действуют с задержкой, копятся нежелательные явления (ЭПС, акатизия, седация, вес, пролактин, удлинение QT, гипонатриемия), меняются анализы. На обходе — дневник наблюдения, психический статус, лист назначений с шагами доз и временем приёма, обследования (ЭКГ, кровь, концентрации лития и вальпроата и др.) и срочные ситуации, которые решает врач: возбуждение, острая дистония, ЗНС, серотониновый синдром, литиевая интоксикация, нейтропения на клозапине, судороги и делирий при отмене алкоголя, энцефалопатия Гайе–Вернике, падения у пожилых, суицидальная попытка.

Каждое назначение куратор сверяет с клиническими рекомендациями Минздрава России (с УУР/УДД там, где они проверены) и стандартами медицинской помощи: первая ли это линия, стартовая доза и скорость титрации, максимальные дозы и дозы у пожилых, противопоказания по сопутствующим болезням, взаимодействия через цитохромы и с лекарствами пациента, полипрагмазия, обязательный контроль. При выписке — оценка (исход, соответствие КР, безопасность, мониторинг, срок) и разбор: в чём был подвох и как вести по рекомендациям. Формуляр — 63 препарата, зарегистрированных в России; 17 пациентов с клиническими ловушками. В справочнике есть вкладки «Препараты», «КР» и архив курации.

### Амбулаторный приём

Участковый психиатр ПНД, врач частной клиники и консультант кафедры ведут своих пациентов месяцами. В первый день принимаешь участок у ушедшей на пенсию коллеги — амбулаторные карты с её записями, старыми анализами и текущим лечением, в каждой есть что заметить: феназепам «на месяц», ставший полутора годами; оланзапин и +18 кг; литий без анализов почти год, вальпроат у женщины, которая хочет ребёнка; клозапин у курильщика, который собрался бросить. Новые пациенты приходят по направлению — сначала предварительный диагноз, потом лечение: депрессия (в том числе у пожилой и послеродовая у кормящей матери), биполярная депрессия под маской «обычной», паника, ГТР с просьбой о феназепаме, ОКР, ПТСР, первый эпизод шизофрении, зависимость от алкоголя, деменция, бессонница. Среди принятых с участка — ещё «резистентная» депрессия, которая на деле недолечена (и гипотиреоз, который никто не искал), и деменция с вечерним беспокойством, которое «лечили» галоперидолом и феназепамом. На первичном приёме психический статус можно **записать самому** в конструкторе (или открыть готовую запись): заведующий проверит её — от 80% запись засчитывается в оценку ведения по КР.

На визите — что было между приёмами (со слов пациента и родственников), осмотр, шкала (PHQ-9, GAD-7, YMRS, PANSS, MMSE и др.), готовые анализы, плановая инъекция пролонга. Врач разговаривает (объяснить лечение, сроки, пропуски таблеток, суицидальный риск, семья, вес, алкоголь, сон, планирование беременности), назначает препараты, дозы и **время приёма** (утром, на ночь, в несколько приёмов — седативные днём мешают, активирующие вечером не дают уснуть, лишние приёмы — больше пропусков), заказывает анализы и выбирает, когда увидеть пациента снова: через 1–2 дня, неделю, две, месяц или два.

Между визитами болезнь и лечение идут своим чередом, время сжато (день в календаре — два дня лечения). Пациенты пропускают таблетки, бросают их из-за побочных эффектов или «потому что стало хорошо», не приходят на приём, звонят: тошнота первых дней, инверсия в манию на антидепрессанте, литиевая интоксикация после НПВС от терапевта, отказ от курения на клозапине, беременность на вальпроате, синдром отмены после резкой отмены феназепама или пароксетина, гипонатриемия у пожилой, падение, сыпь на ламотриджине, срыв при зависимости от алкоголя. Каждый визит разбирает заведующий: интервал, ответ на жалобы, ответ на лечение за 4 недели, обязательный контроль, отмена бензодиазепинов. Когда состояние устойчиво — перевод на редкие визиты и итоговая оценка ведения (исход, КР, безопасность, мониторинг, ведение) с разбором подвоха. Карты всех пациентов участка — в справочнике, вкладка «Участок».

Клинические случаи и пациенты вымышлены, дозы и модель течения упрощены для обучения; игра не заменяет учебник, инструкции к препаратам, действующие клинические рекомендации, супервизию и консультацию врача.

## Устройство

Чистый JavaScript без зависимостей, классические скрипты в общем пространстве `window.A`.

| Папка | Что внутри |
| --- | --- |
| `js/core` | утилиты, календарь, сохранения (localStorage + облако Claude, если доступно) |
| `js/game` | движок времени и показателей, действия, оценка клинических случаев и экзаменов, фармакология (`pharma.js`), отделение (`ward.js`), амбулаторный приём (`clinic.js`), поиск и оценка диагноза по МКБ-10 (`icd.js`), тренажёр (`trainer.js`), конструктор психического статуса (`mse.js`) |
| `js/data` | контент: лекции, клинические случаи, мини-задачи, события, глоссарий, финалы, банк тестовых вопросов (`tests-*.js`), каталог МКБ-10 (`icd.js`), сценарии конструктора психического статуса (`status*.js`), формуляр (`drugs-*.js`), карта КР (`guidelines.js`), пациенты отделения (`ward-*.js`) и амбулаторного приёма (`amb-*.js`) |
| `js/art` | процедурная SVG-графика: сцены со сменой времени суток и сезона, портреты с эмоциями, иконки |
| `js/ui` | экраны и интерфейс |
| `tools` | сборка, проверка данных, автоигрок и симуляция экономики |
| `assets` | шрифты (SIL OFL 1.1) и иконки приложения |
| `docs` | собранная версия для GitHub Pages (PWA, работает офлайн) — генерируется, руками не править |
| `android` | приложение для Android: окно WebView, в которое встроена игра |

Инструменты:

```sh
node tools/validate.mjs                 # проверить формат и согласованность контента
node tools/sim.mjs 180                  # прогнать 180 игровых дней без интерфейса (баланс)
node tools/ward-sim.mjs w_scz_first ideal --runs 30   # курация одного пациента по сценарию (tools/ward-plans.mjs)
node tools/amb-sim.mjs a_dep_first ideal --runs 30    # амбулаторное ведение по сценарию (tools/amb-plans.mjs)
node tools/amb-sim.mjs --all --runs 10 --check         # все амбулаторные пациенты: баланс оценок по КР и с ошибками
node tools/sim.mjs 160 --difficulty hard   # то же на сложном уровне (диагноз — из полного списка МКБ-10)
node tools/build.mjs                    # собрать dist/anamnez.html — игра одним файлом
node tools/build.mjs --site docs        # обновить версию для GitHub Pages (после любых правок игры)
NODE_PATH=$(npm root -g) node tools/autoplay.cjs index.html 600   # автоигрок в headless Chromium (нужен playwright)
NODE_PATH=$(npm root -g) node tools/bridge-test.cjs docs/index.html  # связка игры с Android-приложением
NODE_PATH=$(npm root -g) node tools/trainer-check.cjs docs/index.html # тренажёр, поиск по МКБ-10, уровни сложности и конструктор статуса
```

### Android

APK собирает GitHub Actions (`.github/workflows/android.yml`): проверяет данные, гоняет автоигрока, собирает APK, проходит игру на эмуляторах Android 11 и 15 и выкладывает файлы в релиз `android-vВЕРСИЯ` (хранятся три последних; актуальный APK всегда по ссылке `releases/latest/download/anamnez.apk`). Локально (нужны JDK 17 и Android SDK):

```sh
node tools/build.mjs --site android/app/src/main/assets/www
cd android && ./gradlew assembleRelease     # → app/build/outputs/apk/release/app-release.apk
```

Приложение — одна активность с WebView (`MainActivity.java`). Игра открывается с зарезервированного адреса `https://appassets.androidplatform.net/` прямо из APK, в сеть ничего не уходит. Сохранения дублируются в файлы приложения, системная кнопка «назад» закрывает окна и вкладки игры. Ключ подписи `android/keystore/anamnez.jks` лежит в репозитории намеренно, чтобы обновления ставились поверх; для магазина приложений замени его своим. Иконки рисует `tools/icons.cjs`, шрифты скачивает `tools/fonts.mjs`.

Если вам самим тяжело — обратитесь к врачу или позвоните 112; 8-800-2000-122 — бесплатный телефон доверия для детей, подростков и их родителей.
